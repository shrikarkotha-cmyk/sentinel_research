# V0.10: Simplified launch and OpenGL benchmark pilot

Status: Linux sandbox tested; Windows build and physical GPU testing pending.

The existing adventure remains an internal research testbench. A shared launcher function automatically activates with a valid synthetic storefront grant when no existing license is present, then launches the native game with its original verifier. An optional direct-start flag initiates Play; the developer-operated issuer remains necessary for first activation of a new profile. No real Steam connection exists.

The first development stage passed 49/49 expected portable integration outcomes and 2/2 native CTest checks. The second added a separate desktop OpenGL benchmark scene with 3D geometry, perspective, lighting, eight existing 2048 RGB terrain materials, animated scenery, orbit controls and three scene-density settings. Both the adventure and OpenGL modes enforce native authorization before rendering.

The final clean Linux build passed 53/53 expected portable integration outcomes and 2/2 native tests. An authorized profile completed each of the three 120-frame OpenGL workloads with the issuer stopped. An unauthorized profile was denied before OpenGL initialization. The software credential clone remains a known limitation. Counts include expected weaknesses, not attacks defeated.

One sample per preset: 610.422, 1182.02 and 1445.89 ms for 120 frames at low, medium and high settings respectively. Xvfb with Mesa llvmpipe (LLVM 19.1.7) was the rendering environment, not a physical GPU. These are workload observations including synchronization and swaps, not controlled DRM overhead or display FPS results. The Windows WGL path and launcher UI changes require verification. The updated private workflow is prepared, but no Windows build was triggered here.

Next: run the Windows build with the matching local issuer public key, check actual renderer identity on the physical PC, verify one-click launch and measure repeated equivalent protected and developer-authorized baseline workloads. Load scalability and Sentinel Adaptive remain separate future experiments.
