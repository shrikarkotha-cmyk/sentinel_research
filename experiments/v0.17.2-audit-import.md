# V0.17.2 audited candidate: evidence intake

Status: adopted as the development baseline, not a production release. V0.17.1 remains the rollback and comparison reference.

The supplied audit archive contains 77 entries. Intake independently verified the archive CRCs, SHA-256 (7b21814144bf8086d69958598dd97ad28f4409d71f830d7dc9e2910b25d22478), and all 35 changed-file hashes against the supplied evidence. No conventional private-key PEM markers or key/license/database file extensions were detected in the archive. These checks establish consistency with the supplied report, not independent verification of the reported execution or source provenance.

## Reported improvements
The audit candidate stages and verifies a license before replacing an existing one, requires bound recovery grants (including rejection of legacy unbound recovery rows), serializes credential initialization, restricts packaging to approved files, constrains the local issuer's HTTP handling, and improves Windows Unicode path and ABI buffer handling. The native SDK ABI and V2 license and manifest formats are preserved. Source inspection confirmed the staged verification and packaging allowlist paths. Enhanced enrollment requires operator confirmation of a device public key and does not attest hardware provenance.

## Reported Windows evidence
- 76/76 player integration cases; 10/10 targeted audit regressions; 3/3 native groups per build; 16/16 recovery and 9/9 bound-grant checks; 10 Vault tests passed and one POSIX-only test skipped.
- V0.17.1 licenses accepted by both builds on the same device and disposable trust anchors. Twenty timed warm launches per build/provider: DPAPI median 169.673 to 169.655 ms; TPM median 201.981 to 202.265 ms. These are protected-versus-protected startup observations, not DRM overhead relative to an unprotected build.
- Final matched 50,000-arrival test, four in-process workers: baseline 365.13 requests/s; candidate 365.84 requests/s; candidate total 136.671 s, arrival-to-response p50 68.554 s and p95 128.844 s. Each issued 40,000 verified licenses and rejected 10,000 invalid requests with zero incorrect decisions and successful database integrity checks. This is not a network concurrency or production capacity test. Earlier Linux figures are not directly comparable.
- The RTX 5080 rendered three 120-frame OpenGL presets in approximately 1.97 seconds each. The near-identical results suggest a frame pacing or workload limitation worth checking; no paired unprotected frame-time benchmark exists.

## Remaining qualification
Prioritize release trust, key rotation and recovery drills, independently reproduced platform tests and realistic performance controls. macOS hardware testing remains blocked by the unqualified distribution package; do not bypass Gatekeeper. Native Linux TPM, SteamOS/Proton, real storefront authorization, multi-host capacity and an independent runtime trust assessment remain open. A fully offline player-controlled verifier cannot establish its own independent integrity. Indefinite offline revocation remains a documented tradeoff. No evidence of Denuvo parity or Valve endorsement.

The private Windows workflow has been prepared to accept the exact checksum-pinned audit archive; source import and candidate CI execution remain pending. The supplied raw evidence contains local filesystem paths and is not published here. Starfall Trail remains an internal testbench. Development and audit were AI-assisted; independent reproduction and researcher interpretation remain necessary.
