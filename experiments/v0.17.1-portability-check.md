# V0.17.1: Relocatable packaging and native compile preparation

The V0.17 candidate used platform-specific native credential providers but its package needed independent verification outside the build tree. V0.17.1 adds relative library search paths for Linux and macOS and a provider-neutral, opt-in test utility for isolated development profiles. No changes to license or entitlement policy were made.

## Observed
A clean Linux build passed 3/3 CTest groups. The packaged game and device utility were moved into a temporary directory with spaces, the original build directory renamed, and library-path overrides removed. Nine smoke checks passed: library loading, read-only diagnostic, provider identification, stable credential initialization, signature size, software credential presence, independent signature verification, malformed proof rejection without credential change, and denial of unlicensed launch. The provider was Linux lab software; no hardware provenance claim is made. The 70-file source archive passed ZIP CRC checking and excludes generated signing keys and build outputs. This was a focused smoke run, not the full integration regression suite.

## Native CI preparation
The private repository's manual Windows build workflow now accepts V0.17.1. A separate manual Apple Silicon macOS 26 compile and package relocation check was added using temporary lab signing keys. These workflows have not been run: the new source archive must first be imported into the private repository. Hosted macOS compilation does not verify Secure Enclave operations or physical hardware compatibility. Windows TPM and DPAPI, macOS signing, Keychain access, hardware recovery and a distributable macOS app remain pending. Native builds must precede any physical hardware tests. The opt-in hardware smoke utility creates a new isolated test credential and may leave a persistent OS key; it does not delete keys, change security settings, or access real player profiles. No commercial tamper-resistance or performance claim is made. Independent reproduction remains necessary.
